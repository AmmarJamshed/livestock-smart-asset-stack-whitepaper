# Glossary

| Term | Meaning in this paper |
| --- | --- |
| **SLAS** | Smart Livestock Asset Stack — the five-layer process proposed here |
| **L0 Field capture** | Apps/systems that bind animal ↔ owner in the field |
| **Animal Passport** | Biometric livestock identity / farm platform used as an L0 example |
| **PAITS** | Pakistan Animal Identification & Traceability System (PITB/FAO/GoP) |
| **Registry company** | Legal system of record for animal/batch IDs and access control |
| **Health feed** | Attested, schema-bound health record tied to a registry ID |
| **Mint gate** | Automated + legal checks required before token issuance |
| **PVARA** | Policy / regulatory perimeter referenced for virtual-asset style tokenization |
| **Grid** | Aggregation layer producing daily value feeds |
| **Daily value feed** | Published price / NAV series with methodology and verification % |
| **CDC** | Central Depository Company — custody / book-entry rail (phased) |
| **PSX** | Pakistan Stock Exchange — visibility / possible listing venue (phased) |
| **Promote** | Act of lifting a field ID into the registry company as canonical |
| **Dual-rail** | Using public PAITS keys alongside private biometric capture |
